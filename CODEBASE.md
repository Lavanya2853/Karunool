# CODEBASE.md - KaruNool Project

## 📜 Project Overview
KaruNool is a digital connection platform for the traditional craft communities of Tamil Nadu. It aims to provide visibility to artisans, discovery for buyers, and support for endangered crafts.

## 🛠️ Environment Context
- **OS:** Windows (PowerShell)
- **Primary Languages:** Java (Spring Boot), JavaScript (React)
- **Database:** MySQL
- **Styling:** Tailwind CSS (Modern, Premium Aesthetics)
- **Version Control:** GitHub (`karunool`)

## 🏗️ Architecture
- **Backend:** REST API (Spring Boot)
- **Frontend:** Single Page Application (React)
- **Authentication:** JWT (JSON Web Token)
- **Storage:** Local/Cloudinary (for craft photos)

## 🗺️ System Map
- `karunool-backend/` - Spring Boot Source
- `karunool-frontend/` - React Source
- `.agent/` - AI Agent configuration and rules
